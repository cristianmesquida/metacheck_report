Participants were recruited through a participant database and from the experimenter's network. An a priori power analysis was conducted to determine the required sample. Earlier work by Nazaretsky et al. (2024) examined the effect of feedback source (human vs. AI) on source credibility, reporting a large effect size (d = 0.88). To detect an effect size of Cohen's d = 0.88, a two-tailed Wilcoxon signed-rank test (matched pairs) was used, with 𝞪 error = 0.05 and power = 0.9. This resulted in a required sample size of N = 17. However, to allow for additional analyses involving multiple within-subject measurements, a repeated-measures ANOVA (within factors) was also considered (f = 0.40, 𝞪 error = 0.05, power = 0.9, two groups, five measurements). This resulted in a required sample size of N =28. method apriori
The sample size was calculated based on expected differences in the main dependent variable of interest: self-reported trust. A realistic and meaningful difference between any two conditions would be 0.5 points on a 7-point Likert scale and a 1.53 points standard deviation (Brdnik et al., 2025). Using the Superpower package in R, a sample size of 25 is calculated to achieve a power of 90% (see Appendix A). Five extra participants were added to account for unforeseen issues. Therefore, the recruitment goal for this experiment was 30 participants. method unknown
